# Portfólio de Murilo Henrique Ferreira Nunes

Portfólio de estudante de Eletrotécnica do IFAL – Campus Maceió. Reúne formação, experiência, projetos e uma simulação interativa do campo girante de um motor trifásico.

## Abrir o site

Abra `index.html` no navegador. O projeto usa HTML, CSS e JavaScript e dispensa instalação ou compilação. Cinco ícones de ferramentas são carregados do Wikimedia Commons e precisam de internet.

## Arquivos

| Arquivo | Conteúdo |
| --- | --- |
| `index.html` | Apresentação, formação, experiência e projetos |
| `style.css` | Layout responsivo e cores dos temas claro e escuro |
| `app.js` | Links de contato, menu e botão de retorno ao topo |
| `motor.js` | Animação do motor e interação com as correntes R, S e T |
| `tema.js` | Seleção e persistência do tema |
| `assets/` | Marcas usadas nos cartões de formação e experiência |
